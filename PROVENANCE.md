# Provenance

Every file of the Cargo workspace (the repository root: `crates/`, `sites/`, `testdata/`,
`THIRD_PARTY/`, and the tools it depends on) that is not original work of this rewrite is listed
here: where it came from, at which commit, under which licence, and whether it is used
**verbatim**, **modified** or **rewritten** (REWRITE_PLAN.md §5, §8.1 "Clean room").

Rules:
- fugo is Apache-2.0. Only licences allowed by `deny.toml` may enter the tree.
- Zola 0.22 and later (EUPL-1.2) is a design reference only; its source is never opened or
  copied. Single MIT files from Zola **before commit 3c9131db** may be copied (decision D2 = b):
  fetch the single raw file, commit it verbatim first with an MIT header, add a row here, then
  adapt it in a later commit (and update the row to *modified*).
- Salvage from the old port (`git show go-parity-final:crates/...`, commit `be02933a`) is our
  own Apache-2.0 code; restored files are listed so reviewers can tell kept code from new code.
- Assets that cargo cannot see (syntax definitions, CLDR/emoji data, livereload.js, Hugo's
  embedded templates) also get an entry in `THIRD_PARTY/`.
- `NOTICE` carries the attribution notices the Apache License requires (section 4): fugo's,
  and The Hugo Authors' for the material derived from Hugo listed below. It ships in every
  release archive with `LICENSE`, this file and `THIRD_PARTY/`.
- `testdata/legacy-docs/` is a copy of Hugo's documentation site (the Go tree's `docs/`), kept as
  a test site. Its content is Apache-2.0 (`testdata/legacy-docs/content/LICENSE.md`), but its theme
  (layouts, CSS, JavaScript, images) has no open-source licence (`testdata/legacy-docs/LICENSE.md`),
  and neither has the Tera conversion of those layouts in `sites/docs/layouts/`. They are kept as
  test fixtures and are not in the release archives, and no published site uses them:
  getfugo.github.io is built from `docs/`, fugo's own documentation with its own theme.
- `docs/` (except `docs/rust-port/`) is original work for fugo, Apache-2.0: its content, its
  theme (Tera layouts, Sass, JavaScript) and its data, which the tests generate from the code
  (`docs/data/template_api.json`, `commands.json`) or check against it (`objects.toml`). Its
  sections follow the organisation of Hugo's documentation, and pages that describe behaviour
  fugo shares with Hugo (configuration keys, front matter fields, shortcode arguments) state the
  same facts; the text and examples were written anew, not copied. The logo and icons come
  from `brand/` (mounted as `assets/brand`; row below).
- Paths of this repository's Go tree (Hugo's packages, `go.mod`, `tools/go-oracle`,
  `tools/dev/oracle.sh`) were removed after commit `44529028`; a row names the commit to read
  them at (`git show <commit>:<path>`).
