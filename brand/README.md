# Brand

The fugo logo: an orange cat with goggles in a gear, above the word **fugo**. Cut from the
project owner's brand sheet (2026-10-02); the background was made transparent.

| File | What | Use |
|---|---|---|
| `logo.png` | The logo with the wordmark, transparent, 600×830 | README, website header |
| `mark.png` | The cat in the gear without the wordmark, transparent, 512×512 | avatars, app icons |
| `icon-180.png` | The mark on white, 180×180 | `apple-touch-icon` |
| `favicon.ico` | The mark at 16, 32 and 48 px | browser tab icon |
| `social-preview.jpg` | The logo with the tagline, 1280×640 | GitHub's social preview (repository settings) |

Colours: wordmark orange `#FA9E2F`, outline navy `#082341`, gear `#0E1215`.

The logo works on light and dark backgrounds. Keep it whole: don't recolour it, crop the cat out
of the gear, or put it on a busy background. The name and the logo identify the project; the
Apache License 2.0 of this repository grants no trademark rights (section 6).
