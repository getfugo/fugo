---
title: Custom 404 page
description: Write the page your host shows for missing URLs.
weight: 110
---

`layouts/404.html` renders `/404.html`, with the home page as `page`:

```html {title="layouts/404.html"}
{% extends "baseof.html" %}
{% block main %}
  <h1>Page not found</h1>
  <p><a href="{{ site.home.rel_permalink }}">Go to the home page</a></p>
{% endblock main %}
```

GitHub Pages, Netlify, Cloudflare Pages and most hosts serve `/404.html` for missing URLs
without configuration. `fugo server` serves it too. A multilingual site gets one per language
(`/th/404.html`).
