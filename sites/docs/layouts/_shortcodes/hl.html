{#- Returns syntax-highlighted code from the given text. This is useful as a terse way to highlight inline code snippets. Calling the highlight shortcode for inline snippets is verbose. @example This is {{< hl python >}}inline{{< /hl >}} code. -#} {%- set code = inner | trim %} {%- set code_lang = (shortcode | arg(index=0, default="")) or "go" %} {{- code | highlight(lang=code_lang, options={"hl_inline": true, "noClasses": true}) }}
