# T65: docs parity (A-D1, `--docs-patches i01`)

The first docs-i01 baseline: `testdata/baselines/docs-i01.json`. Rust vs Go: L1 888/888 in
both passes, the structure oracle 1728/1728, L2 756/756, L3 748/750 (heading-ID lists equal on
every page), L4 100/100, A7 0.9987 (748/749 pages with equal visible text).

Fixed before the baseline (so no `bug-fixed` entries; the differences never reached a baseline):

- The Go-side GitHub API stub (`sites.py` DOCS_WRITE) held ints, so Go's
  `printf "%0.1fk" (div 76543 1000)` printed `%!f(int64=76)k` on every page. The stub now holds
  floats, which is what `resources.GetRemote | transform.Unmarshal` gives in Go; the Tera patch
  keeps ints (the Rust `unmarshal` gives Int for integral numbers). Golden docs-i01 and
  docs-reduced regenerated with `oracle.sh sites docs-i01 docs-reduced`.
- `remarshal(format="json")` escapes `<`, `>`, `&` like Go's `json.MarshalIndent`
  (code-toggle samples on configuration/markup, configuration/menus, content-management/menus,
  configuration/module).
- `remarshal` of TOML keeps date-times as text: a local date stays `2023-01-01`, as go-toml's
  `LocalDate` marshals (methods/page/param).
- `page.alternative_output_formats` leaves out `notAlternative` formats (the home page's
  `_headers` link).
- A processed image keeps its source's EXIF orientation, so `auto_orient` after a resize
  orients it (functions/images/autoorient, orientation 5: 256x384).
