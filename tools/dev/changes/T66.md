# T66: docs A-D2 (`--docs-patches reduced`)

The first docs-reduced baseline: `testdata/baselines/docs-reduced.json`. The reduced
variant keeps Chroma highlighting (code fences, `highlight`, `hl` inline with `noClasses`,
`shortcodes/highlight.md`), GoAT diagrams, emoji, passthrough with `to_math`, `remarshal` in
`code-toggle`, Tailwind through `defer` and the real Alpine/Turbo `js_build`.

Fixed before the baseline (so no `bug-fixed` entries):

- `diagrams_goat` is implemented (svgbob, feature `goat` of the funcs crate); the CLI crate
  enables the features `goat` and `math` by default, so the shipped binary renders the docs' diagrams
  and formulas.
- `remarshal` to YAML and TOML writes what yaml.v2 and go-toml v2 write: YAML strings plain,
  single- or double-quoted by yaml.v2's rules (literal blocks for multi-line text), yaml.v2's
  key order; TOML literal strings (`'…'`) and keys, TOML dates bare; integral floats of maps as
  integers; Go's `%g` floats in YAML (140 code-toggle pages).
- The harness (`manifest.py`) no longer splits words at the token spans of highlighted code
  (`span` inside `pre`/`code`): the span structure is an allowed difference (§7.3), and Chroma
  and syntect tokenize differently. Golden docs-reduced unminified manifest regenerated with
  `oracle.sh sites docs-reduced` (the other labels' manifests do not change).

Checked by hand (equal or allowed): `shortcodes/highlight/` has the same Chroma classes and
inline styles (`noClasses`, `hl_inline`); `quick-reference/emojis/` is L3-equal; the JS bundles
(`main.js` with Alpine, `turbo.js`) are byte-equal; the Tailwind CSS differs only by the CSS
minifier (allowed).
