# T74: docs-live — the published documentation site (gate A-D3)

The documentation site without patches (`sites.py make docs-live`, `docs/` with the Tera overlay
`sites/docs`), compared with the site https://getfugo.github.io/ publishes: the first docs-live
baseline, `testdata/baselines/docs-live.json`, against `testdata/golden/docs-live/` (the
manifest of getfugo/getfugo.github.io at a1928152, the Go version's build of 2025-10-13). The engine
work that made every page equal also fixes the remaining docs-reduced and docs-i01 differences:

- `get_remote` sniffs the media type with Go's whole `http.DetectContentType` table (fonts,
  audio, video, WebAssembly, …): the `images.Text` example's font is served as
  `application/octet-stream`.
- Content adapters: `content/**/_content.html` Tera templates (`add_page`, `add_resource`,
  `enable_all_languages`, `site`, the adapter's store), run while the content is collected;
  the docs' news adapter is ported (`sites/docs/content/en/news/_content.html`).
- `to_math` runs KaTeX 0.16.22 with mhchem in QuickJS (rquickjs), as the Go implementation runs it,
  with its options (`output`, `displayMode`, `macros`, `strict`, …).
- `diagrams_goat` is a port of bep/goat v0.5.0 (svgbob removed).
- The `smart` anchor is a port of muesli/smartcrop v0.3.0 with the Go implementation's analysis resize.
- Pipe tables are goldmark's paragraph transformer (lazy continuation lines, padded header
  rows, the retry before setext underlines and definitions); `{{% %}}` output inside indented
  blocks is indented as the Go implementation does.
- Highlighting is a port of Chroma v2.19.0 (its lexers, engine and HTML formatter; syntect and
  two-face removed).

Checked by hand (equal or allowed): the JS bundles built with `tools/docs/package-lock.json` are
byte-equal to the published ones; the Tailwind CSS differs only by the CSS minifier
(lightningcss writes `transparent`/`rgba()` where Go's minifier writes `#0000`/`#00000080`, and
Tailwind's automatic source detection reads the Tera layouts instead of the Go ones); all 773 QR
codes and every static file are byte-equal; processed images have Go's sizes and differ by
resampling noise (mean pixel difference ≤ 0.017; Dither 0.17, its error diffusion amplifies that
noise); the extra empty table row Go writes after an included table ending a page
(functions/resources/getmatch, match, methods/page/resources: the Go implementation's closing context
marker line read as a table row) is not reproduced; the generator is the Go version's name with
`0.149.0-DEV`.
