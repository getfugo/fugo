# T75: a Rust-only asset pipeline

The external tools are gone: the PostCSS, Babel and Tailwind pipes (and the machinery that ran
node tools: `exec`-style tool lookup, the tools' configuration-file mounts and cache busters),
the embedded JavaScript runtime that ran npm packages' binaries, and the stats file that
`[build.buildStats]` wrote for Tailwind (`[build] writeStats` and `[build.buildStats]` are now
"no longer supported" warnings). npm package installation stays (for `js_build` and Sass
imports); `minify` adds vendor prefixes and `purge_css` purges per page, scanning each page
itself.

The legacy docs site's Tailwind stylesheet is published from its recorded output
(`sites/docs/assets/css/styles.tailwind.css`, PROVENANCE.md), the same bytes the Tailwind
pipeline built, so the docs gates' files and assets are unchanged.

The golden manifests keep the Go build's stats file (written next to its configuration, the
`project:` keys); structdiff.py now leaves those entries out, so they are gone from both sides:

- docs-i01 L3 `project:*` accepted-deviation: the Go build's stats file is not compared: this port writes none (Tailwind and `[build.buildStats]` removed)
- docs-reduced L3 `project:*` accepted-deviation: the Go build's stats file is not compared: this port writes none (Tailwind and `[build.buildStats]` removed)
- docs-live L3 `project:*` accepted-deviation: the Go build's stats file is not compared: this port writes none (Tailwind and `[build.buildStats]` removed)

Gate counts: A-T L1 55 (was 56), A-D2 888 (was 889), A-D3 2372 (was 2373).
